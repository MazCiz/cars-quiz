# Cars Quiz

## Features

- 10-question quiz — budget, main use, passengers, driving environment, fuel, priority, transmission, mileage, cargo, and tech importance. Questions live in Postgres (seeded) and are fetched through the API.

- AI recommendation — on completion, the answers are sent to Claude (claude-opus-4-8), which writes a short, personalized recommendation grounded in the user's answers. Falls back to a rule-based suggestion when no API key is set, so it always works.

- Attempt tracking — each completed quiz is stored as an attempt with its answers, and the time spent on every question is recorded in milliseconds; the total completion time is shown to the user.

- Metrics panel (/metrics) — aggregate stats across all attempts: approximate average time per question and which answers get clicked most (most-picked highlighted).

- Suggest a question (/suggest) — a simple form where users can propose new questions; these are saved to their own table for review and never added to the live quiz.

- Adminer — a browser-based DB viewer at http://localhost:8080 for inspecting the Postgres schema and data.

## Prerequisites

- Node.js + npm
- PHP 8.2+ and Composer
- A Docker runtime

## Getting started

```bash
# 1. PostgreSQL (host port 5433)
docker compose up -d

# 2. API — Laravel on http://localhost:8000
cd api
cp .env.example .env        # DB settings already point at the compose Postgres
composer install            # if dependencies aren't installed yet
php artisan key:generate    # if APP_KEY is empty
php artisan migrate
php artisan serve --port=8000

# 3. Web — Next.js on http://localhost:3000
cd web
npm install
npm run dev
```

Open http://localhost:3000 — you should see the API and PostgreSQL reported as
**connected**.

## The quiz

A 10-question quiz that recommends the kind of car that suits the user, with an
**AI-generated** personalized recommendation on completion.

**To enable the AI recommendation**, add your key to `api/.env`:

```
ANTHROPIC_API_KEY=sk-ant-...
# optional: ANTHROPIC_MODEL=claude-opus-4-8
```

Then `php artisan config:clear` and re-run the quiz — the result's badge shows
"Generated by Claude" instead of "Rule-based suggestion".
